# Projet ENSAN 2026

Ce projet analyse des données pédagogiques simulées sur la sécurité alimentaire
et la vulnérabilité des ménages.

## Exécution

1. Ouvrir `mon_projet.Rproj` dans RStudio.
2. Exécuter `R/01_import.R`.
3. Exécuter `R/02_nettoyage.R`.
4. Exécuter `R/03_analyse.R`.
5. Compiler `rapport/rapport_final.qmd`.

Les données brutes restent dans `data/raw/`. Les données nettoyées sont placées
dans `data/processed/`, les graphiques dans `output/figures/` et les tableaux
dans `output/tables/`.
